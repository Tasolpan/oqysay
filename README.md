# оқыSAY — мектепішілік оқырмандар платформасы (демо)

Бұл — «Кітап оқитын ұлт» аясындағы «оқыSAY» жобасының GitHub Pages үшін арналған, қазақ тіліндегі интерактивті көрсетілімдік нұсқасы.

## Қолдану

- Басты бет: ТОП-10 үлгі рейтингі, үздік сынып, шығармашылық жобалар.
- Рейтинг: осы апта және өткен апта, сыныптар рейтингі.
- Кітапхана: іздеу, санаттар, 12 кітаптың сипаттамасы және қысқа тест.
- Оқушы: әр жаңа дұрыс кітап тесті үшін +10 ұпай, шақыру коды `OKYSAY-7A`, шығармашылық жұмыс ұсыну.
- Ата-ана: демодағы оқушы жетістіктерін көрсету.
- Мұғалім: сынып кодын көшіру, үлгі оқушылар, ұсынылған жұмысты мақұлдау.

## Маңызды шектеу

Бұл — **демонстрациялық прототип**, толық тіркелуі бар мектептік жүйе емес. Рөлді ауыстыру жүйеге кіру/рұқсат бақылауы емес. Ұпай, жұмыстар, тест нәтижесі тек осы браузердің `localStorage` жергілікті жадында сақталады. Басқа телефонға синхрондалмайды, браузер деректерін тазаласаңыз жойылады. Оқушы аттары мен статистикасы — ойдан алынған үлгі. Жеке деректерді демоға енгізбеңіз.

Толық жүйе үшін Firebase Authentication, Cloud Firestore, Firestore Security Rules, мұғалімнің сыныпқа шақыруы және растауы, ата-ананы баламен байланыстыру, модерация және деректерді қорғау қажет.

## GitHub Pages

`index.html`, `style.css`, `app.js` файлдары репозиторий түбірінде орналасуы тиіс. Settings → Pages → Build and deployment → Deploy from a branch → `main` → `/(root)` → Save.
